Features
	•	Fly Mode
Toggle smooth free-flight with camera-based directional control.
	•	Speed Boost
Instantly switch between default walk speed and enhanced movement.
	•	Keybind Controls
	•	F → Toggle Fly
	•	G → Toggle Speed Boost
	•	Smart Restrictions
	•	Speed boost automatically disables when flying
	•	Prevents conflicting movement states
	•	Automatic Cleanup
	•	Resets states on character death or respawn
	•	Customizable
	•	Easily adjust fly speed and walk speed values

Installation
	1.	Open Roblox Studio
	2.	Go to: StarterPlayer > StarterCharacterScripts
    3.	Create a LocalScript
	4.	Paste the script into the LocalScript
	5.	Play-test the game

Configuration
You can modify these values at the top of the script:
local FLY_SPEED = 50
local WALK_SPEED = 100
local NORMAL_SPEED = 16
Adjust them to fit your game or testing needs.
